إعدادات الربط الحي (MQTT & MindAR)

خطوات تشغيل الـ WebAR على موبايلك في 5 دقائق

  1. جهّز ملف الهدف (targets.mind): صوّر لوحة التحكم (أو اطبع صورة واضحة)، وارفعها على أداة MindAR Image Targets Compiler وحمّل ملف targets.mind وحطه في نفس مجلد ملف الـ HTML ده.
  2. افتحه عبر HTTPS: متصفحات الموبايل بتشترط HTTPS لفتح الكاميرا. ارفع الملفين على GitHub Pages مجاناً، أو شغّل سيرفر محلي واعمله نفق بـ ngrok http 8000.
  3. اربط الـ MQTT Broker: اضغط على إعدادات MQTT، واتصل بالـ Broker (الافتراضي wss://broker.emqx.io:8084/mqtt شغال للتجربة الفورية بدون إعداد سيرفر).
  4. شغّل الكاميرا: اضغط تشغيل كاميرا AR ووجّه الموبايل للصورة؛ هتظهر بطاقة القراءات 3D فوقها، وأي رسالة JSON على topic الـ ai_proposal هتظهر فوراً بأزرار Approve / Reject.
